# Sales-Performance-Analytics-Dashboard
Power BI Sales Performance Analytics Dashboard with Target Achievement, Regional Manager Analysis, Returns Analysis and Delivery Performance Insights.

## Project Overview

This project focuses on analyzing sales performance, target achievement, regional manager performance, returns, and delivery efficiency using Power BI.

The objective was to transform raw business data into actionable insights that support data-driven decision-making.

## Business Problem

Business stakeholders needed a centralized dashboard to:

* Monitor sales performance
* Track target achievement
* Evaluate regional manager performance
* Analyze product returns
* Monitor delivery delays
* Identify business risks and improvement opportunities

---

## Dataset Used

The project uses four datasets:

* Orders
* Returns
* People (Regional Managers)
* Sales Targets

---

## Key Features

### Executive Summary

* Total Sales

* Return Percentage
* Target Achievement Percentage

### Regional Manager Analysis

* Sales by Regional Manager

* Regional Performance Comparison

### Category Target Analysis

* Sales vs Target Comparison
* Category Achievement Percentage

### Returns & Delivery Analysis

* Return Rate Analysis
* Delivery Delay Analysis
* Shipping Performance Evaluation

### Business Risk Assessment

* Key Risks Identification
* Strategic Recommendations

---

## Key Insights

* Achieved 101.66% of overall sales target
* Technology was the highest-performing category
* Furniture category achieved only 74.2% of target
* Central region generated the highest sales revenue
* Return rate was 6.18%
* Standard Class shipments had the longest delivery duration
